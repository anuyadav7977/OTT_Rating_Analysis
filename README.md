**OTT RATING ANALYSIS**
 
 
 **Project Overview**
This project analyses IMDb ratings of Amazon Prime movies. It finds the average rating, best and worst movies, and allows searching any movie by its name.

 
 **Objective**
- To find the average IMDb rating
- To find the highest and lowest rated movies
- To show the Top 5 movies
- To search a movie by its name

 
 **Technology Used**
- Python
- Pandas Library
- Google Colab
- Kaggle Dataset


   **Dataset**
Amazon Prime Movies dataset from Kaggle. It has 8127 movies. Each movie has its name, language, IMDb rating, running time and year of release.

 
 **How To Run**
1. Open Google Colab
2. Upload the CSV file
3. Run the code
4. Enter a movie name to search
